# DSC 时空查看器 V1.0.0

## 开始使用

双击 `DSC_Viewer_V1.html`，或双击 `启动查看器.cmd`。推荐使用新版Chrome或Edge。无需Python、服务器、网络或安装。

1. 将一个四维原始DSC幅度信号 `.nii` / `.nii.gz` 拖入页面，或点“选择DSC文件”。
2. 核对尺寸、体素间距、基线帧数和帧间隔。时间单位/TR缺失时，软件暂填1.5秒但不会自动计算，需要用户确认并点击应用。
3. 等待后台计算。没有掩膜时使用信号前景阈值，不是脑组织分割；可另载入相同尺寸、相同空间的三维NIfTI掩膜。
4. 同步播放各层，点击切片选点；曲线区灰色为原始、蓝色为平滑结果；切片方向—时间图可点选。
5. 修改基线、前景或平滑参数后点“应用处理”。色标、透明度及图层可直接调整。
6. 导出当前页切片PNG、当前选点全时序CSV、处理记录JSON。大于24层时可翻页。处理太慢可点“取消/重置”。

## 支持范围

- NIfTI-1 单文件、标量三维空间＋时间，支持.nii和gzip压缩.nii.gz。
- 动态文件至少4帧；可选掩膜为三维或单帧。尺寸与仿射必须匹配，软件不做重采样配准。
- 支持大小端以及uint8/int8/int16/uint16/int32/uint32/float32/float64和scl_slope/scl_inter。
- 支持qform、sform及空间/时间单位转换；未声明空间单位会明确提示暂按毫米。
- 暂不支持DICOM序列、NIfTI-2、.hdr/.img、复数/RGB、多回波五维文件或三维Tmax/CBF等参数图。需先转换/选择四维原始信号。
- 为控制浏览器内存，最多8000万数值；gzip解压后最多600MB。极大数据仍可能受设备内存限制，建议裁剪或拆分。
- 基线默认前min(8,总帧数/5向下取整)帧，不自动定位团注。务必确认该时间段是否为团注前。

## 处理定义

每个原始体素计算 S0=前N帧均值，Cproxy=−ln(S/S0)，不额外归零，不除TE，保留负值。任一时间点信号非正值或非有限的体素被排除，数量会显示。

无外部掩膜时，使用基线信号大于全体正值基线P99×用户百分比作为前景；不声称去除头皮或等同BET。P99由最多约10万个等间隔抽样体素计算。掩膜外为内部零哨兵，显示/导出时会明确标为掩膜外，而非零浓度。

先做时间高斯平滑（端点延拓，sigma以秒转换为帧），再做切片内掩膜归一化高斯平滑（按两个面内物理间距分别转换sigma）。核半径ceil(3sigma)。不跨层平滑、不层间插值。平滑尺度可以设0关闭；导出的曲线仍有原始对照。

背景灰度窗与jet上下限在全体切片/时间固定；jet默认−0.10至0.65，可更改。显示范围外颜色饱和，不修改数值。等值线固定0.10/0.20/0.30。

## 解释范围

同一文件为一个病例，逐体素取样不提升采集分辨率。显示采集i/j/k轴及头信息坐标，未做标准轴重定向；“切片方向”不保证严格为解剖头脚轴。无逐层采集时间、运动、泄漏校正。不从动态色彩推断传播速度、血管、组织或病灶类型。不是绝对浓度、CBF或Tmax，供研究演示。

## 隐私与复现

没有网络请求、上传、遥测、外部脚本/CDN或自动云存储。打开官方格式定义链接会访问外部网站；不附带文件数据。默认不持久保存数据，关闭页面后需重载。所有导出均由用户点击并保存到本机。

处理记录JSON含文件名与参数，请自行决定是否对外分享。原始文件不被改写。

仓库源代码在 `src/` 中，压缩发布包的源码在 `source/` 中；测试范围及结果见 `VALIDATION.md`。此版本未在原生PowerPoint或自动化浏览器中作UI兼容验证。


## 源码与构建

```text
DSC_Viewer_V1.html      可直接双击打开的V1发布页面
DSC_Viewer_V1.0.0.zip   可离线分发的完整发布包
src/core.js            NIfTI解析与数值处理
src/worker.js          后台文件加载与处理
src/ui.js              交互与导出
src/shell.html         界面模板
tests/core.test.cjs    不含患者数据的核心回归检查
build.py               仅依赖Python标准库的打包脚本
```

运行 `python build.py` 会在 `release/` 中重新生成单文件软件及发布包。仓库根目录HTML为本次冻结的V1版本。运行 `node tests/core.test.cjs` 可执行核心回归检查，不需要患者文件或第三方Node依赖。

不提交患者影像、脑掩膜、真实曲线缓存、真实病例测试夹具或本机数据路径。README、验证记录中的病例标签仅为匿名测试代号。尚未指定开源许可证；公开仓库不等同于授予特定许可证。
